# VideoGrab — تطبيق أندرويد لتنزيل الفيديوهات

تطبيق Kotlin + Jetpack Compose مبني على مكتبة **youtubedl-android** (yt-dlp + ffmpeg)،
يعمل مباشرة على الهاتف بدون سيرفر.

## المزايا
- لصق رابط (بزر اللصق) أو **المشاركة من المتصفح/أي تطبيق** إلى التطبيق مباشرة.
- جلب معلومات الفيديو: الصورة المصغرة، العنوان، المدة، والجودات المتاحة مع الحجم التقريبي.
- اختيار الجودة: أعلى جودة / 1080p / 720p ... / **صوت فقط (MP3)**.
- تنزيل في **خدمة أمامية (Foreground Service)** مع إشعار تقدم وزر إلغاء، يستمر والتطبيق في الخلفية.
- **قائمة انتظار** (تنزيل واحد في كل مرة) مع شريط تقدم والوقت المتبقي.
- إلغاء، إعادة المحاولة، تشغيل، مشاركة، وحذف (من القائمة فقط أو مع الملف).
- سجل التنزيلات محفوظ بعد إغلاق التطبيق.
- الحفظ في المعرض: `Movies/VideoGrab` للفيديو و `Music/VideoGrab` للصوت (عبر MediaStore).
- الإعدادات: Wi-Fi فقط، تحديث yt-dlp تلقائيًا (مرة يوميًا) أو يدويًا.
- واجهة عربية/إنجليزية (RTL)، وألوان ديناميكية (Material You) على أندرويد 12+.

## طريقة التشغيل
1. ثبّت **Android Studio** (إصدار حديث، يتضمن JDK 17).
2. `File ▸ Open` واختر مجلد `VideoGrab`، وانتظر انتهاء Gradle Sync (يحتاج إنترنت).
3. وصّل هاتفك (تفعيل USB debugging) أو شغّل محاكيًا ثم اضغط **Run ▶**.
4. لبناء APK: `Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)`.
   - ستجد ملفات APK لكل معمارية (arm64-v8a وغيرها) + ملف universal في `app/build/outputs/apk/`.
   - معظم الهواتف الحديثة: استخدم `arm64-v8a`.

## ملاحظات
- أول تشغيل أبطأ قليلًا لأن المكتبة تفك ضغط Python/yt-dlp/ffmpeg.
- إذا فشل Sync بسبب رقم إصدار المكتبة، غيّر `ytdlVersion` في `app/build.gradle.kts`
  إلى آخر إصدار في صفحة المكتبة على GitHub.
- إذا توقف موقع عن العمل: **الإعدادات ▸ تحديث المحرك الآن**.
- نزّل فقط المحتوى الذي تملكه أو المسموح لك بتنزيله. المحتوى المحمي بـ DRM غير مدعوم.
- التطبيق للاستخدام الشخصي/التعلم؛ متجر Google Play يرفض عادةً هذا النوع من التطبيقات.
